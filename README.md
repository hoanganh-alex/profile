# Nguyễn Hoàng Anh (Alex) • Profile Bio

Trang cá nhân hiện đại với phong cách siêu xe Apollo Project EVO, tông màu Electric Aqua / Cyan, hỗ trợ nhạc nền liên tục, hiệu ứng động mượt mà và tích hợp Discord Realtime Presence.

## 🚀 Tính năng nổi bật
- **Apollo Project EVO Aero Design**: Đèn LED chữ X, viền laser chạy quanh card, con trỏ Cyber HUD.
- **Electric Aqua & Modern Cyan Theme**: Giao diện sắc nét, hỗ trợ cả Light Theme và Dark Theme.
- **HQ Music Player**: Danh sách 12 bài hát tuyển chọn chất lượng cao, tự động chuyển bài liên tục.
- **Discord Realtime Integration**: Hiển thị trạng thái Online, game đang chơi, nhạc Spotify qua Lanyard API.
- **Responsive & Zero-Scroll**: Thiết kế chuẩn Bento Grid, vừa vặn khung hình 100vh trên mọi độ phân giải.

## 🛠️ Công nghệ
- HTML5, Vanilla CSS3, JavaScript (ES6+)
- Discord Lanyard WebSocket API
- FontAwesome 6 Pro/Free & Google Fonts
